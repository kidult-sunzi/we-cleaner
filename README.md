# 小红车清理工具（WE Cleaner）

这台电脑只要登过别人的 Steam 账号（代练、借号），Steam 就会把**那个账号订阅的创意工坊内容**也下载到本机；而小红车只显示你当前登录账号的列表，所以软件里看不出任何异常，你只能看到硬盘几十 G 不见了。

更麻烦的是**手动删文件夹没用**：订阅记录还留在 `appworkshop_431960.acf` 里，Steam 校验完整性时以为文件丢了，又会下回来。本工具按 `subscribedby` **只删别人的订阅记录，自己的一张不动**，再顺手清掉已经下下来的缓存。

只动本机文件：改一个配置；431960 下载缓存**由你自己删**，工具只负责把文件夹打开。**不删壁纸文件、不改云端订阅、不联网、不改 Steam 程序文件**。

## 怎么用 

1. 下载 `we-cleaner.exe`，**双击打开** —— 不用装 Python、不用解压、不用安装。
2. Steam 正在运行的话，点一下「一键退出 Steam」；直接点「一键清理」工具也会先帮你退出。
3. 在上面**点一下你自己的账号**（显示昵称 + 壁纸数量 + 账号尾号，不用记任何数字）。
4. 点蓝色大按钮「一键清理」，确认一次就完事。

用完可以点「一键启动 Steam」开回去。

### 按钮说明

| 按钮 | 作用 |
|---|---|
| 一键退出 / 启动 Steam | 正常退出（不强杀、不丢下载）/ 从注册表找 `steam.exe` 启动 |
| 只清下载缓存 | 先弹窗说明怎么删，点「点击前往」打开 `downloads` 文件夹并选中 `431960`，**由你自己按 Delete 删除**；工具不替你删任何文件 |
| 还原备份acf文件 | 用最近一次**能正常解析**的自动备份覆盖 `appworkshop_431960.acf`，坏备份会跳过 |
| 前往删除旧备份 | 显示累积了几个旧备份、占多大，点一下打开文件夹；**由你自己在资源管理器里删**（进回收站、可恢复），工具不代删。别删没有后缀的配置文件本体 |

每次修改前自动在同目录生成 `appworkshop_431960.acf.bak-<时间戳>`；选错账号直接点「还原备份acf文件」再重来。

> **注意**：这个按钮只还原配置文件，**不管下载缓存**；缓存需要自己在文件夹里删除，工具不提供缓存还原功能。

## 下载缓存怎么清

点「只清下载缓存」→ 弹窗里点「点击前往」→ 工具打开 `workshop\downloads` 并选中 `431960` 文件夹 → **你自己按 Delete 删掉它**。

工具**不替你删任何缓存文件**。原因是缓存里 159 个文件有 106 个是图片/视频，360 等安全软件的反勒索规则会把「陌生程序删图片」判成敲诈病毒并弹窗；换成系统外壳的删除动作实测仍然会弹。交给资源管理器由你手动删，既不会被拦，也更清楚删了什么。

- **只删 `431960` 这一个文件夹。**
- 旁边的 `state_431960_*.patch` 是 Steam 的下载状态记录（一共才几 KB），**不要删**：订阅记录还在时删掉它们，可能让 Steam 重新校验、重新下载。
- **不要删** `appworkshop_431960.acf`（配置文件，工具要读）和 `workshop\content\431960`（已经装好的壁纸）。
- 删完如果送进了回收站，**要清空回收站**才会真正腾出磁盘空间。

## 第一次打开可能被拦

exe 没有代码签名，Windows 可能弹蓝色「Windows 已保护你的电脑」，杀软也可能误报。
这不是病毒：工具不联网、不读取账号密码、不改 Steam 程序文件。点「更多信息 → 仍要运行」即可。
想核对可比对同目录的 `we-cleaner.exe.sha256.txt`，源码全部公开。

**执行「一键清理」时**，360 安全卫士 / 腾讯电脑管家等的**主动防御**可能弹窗，
因为它看到「一个陌生的未签名程序在改 Steam 的配置文件」。这是行为拦截，不是查到病毒：
在弹窗里选「允许本次操作」，或把 `we-cleaner.exe` 加入安全软件的信任/白名单即可。

清下载缓存那一步工具**不删文件**，只帮你打开文件夹，所以不会再触发 360 的「删图片」拦截。

## 前提

- Windows 10 / 11（Steam 自 2024-01-01 起已停止支持 Win7 / 8 / 8.1）。
- WebView2 Runtime：Win11 与常规 Win10 自带；万一缺了，工具会弹中文提示而不是白窗。
- Steam 必须完全退出才能改配置，工具会自己检查；查不到进程状态时一律拒绝写入。

## 改完之后怎么确认

不用翻日志，也不用懂英文，看两处就行：

1. **重新打开工具**：账号列表里只剩你自己那个号，说明别人的订阅记录已经清掉了。
2. **重启 Steam 用一会儿**：硬盘占用不再往下掉、也没有又开始下载壁纸，就说明没有被重新拉回来。

下次再登别人的号，还会再下回来，到时候再点一次「一键清理」就行 —— 它不是一次性修复。

Steam 客户端更新可能改变 acf 结构，届时工具会提示「校验没通过，已中止」并停止，不会误删。
另外 Steam 生成的 acf 顶层本身多一个 `}`，所以校验用「删除前后括号差值守恒」，不是绝对配平。

## 别做的事

- **不要手动删 `content\431960` 里的壁纸文件**，Steam 会重新下载一遍再自己删一次。
- 这属于官方未支持的本地缓存操作；备份留着，随时能还原。

## 源码与构建

- `app.py` 图形界面主程序、`gui.html` 界面、`clean_acf.py` 核心逻辑（可独立命令行运行）。
- `python build.py` 重新打包，产物在 `dist/`，同时生成 SHA256。
- `we-cleaner.exe --smoke` 是无人值守自测：开窗 2 秒自动关，退出码 0 即正常。
- 诊断日志 `%TEMP%\we-cleaner.log`：记方法名、耗时与启动状态，**不含账号或 ID**；出错时会写入含文件路径的堆栈，便于排查。

高级用法（命令行）：

```
python clean_acf.py --list                     # 只列账号分组，只读
python clean_acf.py --mine <9位账号ID> --apply # 跳过交互
python clean_acf.py --restore                 # 从最近备份还原
```
