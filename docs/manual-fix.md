# 小红车壁纸反复下载、硬盘被占满：手动解决教程

> 这份教程不依赖任何第三方工具，全部用 Steam 和小红车自带的功能完成。
> 三种方案按「代价从小到大」排列，先试方案一，不行再往下走。

---

## 先判断你遇到的是哪一种

| 现象 | 属于哪种 |
|---|---|
| 取消订阅了，但文件夹还在，硬盘空间没回来 | A：残留文件，不会重下 |
| 硬盘里冒出别人的壁纸，还一直在下载 | **B：别的账号的订阅被拉下来了**（本文重点） |
| 自己的壁纸反复重新下载、下载进度反复归零 | C：Steam 下载缓存坏了 |

**B 的原因只有一句话**：Steam 的创意工坊订阅是**跟着账号走**的，不是跟着电脑走。
这台电脑上登录过别人的 Steam 账号，Steam 就会把那个账号订阅的壁纸也下载下来。

**顺便说清一个常见误解**：关掉 Steam 的「云同步」**没有用**。
云同步管的是游戏存档文件，创意工坊订阅是账号级的数据，两者是两套东西。
关掉只会让你自己的游戏存档失去云端备份。

---

## 方案一：官方重置订阅（最省事，先试这个）

这是 Wallpaper Engine 官方文档给的步骤（`help.wallpaperengine.io/debug/reset.html`）：

1. **完全退出 Steam**（托盘图标右键 → 退出）。
2. 用浏览器打开小红车的创意工坊页面，并登录你的 Steam 账号：
   `https://steamcommunity.com/app/431960/workshop/`
3. 在页面右侧，鼠标移到 **Your files**，点 **Subscribed Items**（已订阅物品）。
4. 点右侧的 **Unsubscribe From All**（全部取消订阅）。
   这一步会清掉你账号下所有订阅，**包括那些在小红车里看不见的隐藏订阅**。
5. **重启 Steam**，订阅就重置了。

**注意**：这一步只清**你当前登录的这个账号**的订阅。
如果问题是别人的账号造成的，这个办法管不到——继续看方案二。

---

## 方案二：清掉别人账号留在本机的记录（推荐，不用重下自己的壁纸）

原理：Steam 会在本机留一个订阅记录文件。把里面属于别人账号的条目删掉，
Steam 就不会再认它们，还会连已下载的文件一起清掉；而且不会写回来——
**除非你再登那个号**。

改之前必须备份，这是唯一不能省的一步。

### 步骤

1. **完全退出 Steam**
   托盘图标右键 → 退出。然后按 `Ctrl+Shift+Esc` 打开任务管理器，
   确认列表里没有 `steam.exe` 和 `steamwebhelper.exe`。

2. **完全退出小红车**
   包括右下角托盘里的 `ui32.exe`。只关掉壁纸画面不算退出。

3. 打开这个文件夹（`<你的Steam库>` 换成你实际装游戏的盘）：
   ```
   <你的Steam库>\steamapps\workshop
   ```
   里面应该有一个 `appworkshop_431960.acf`。

4. **先备份**：把 `appworkshop_431960.acf` 复制一份，
   改名成 `appworkshop_431960.acf.备份`，放在同一个文件夹里。

5. 右键 `appworkshop_431960.acf` → 打开方式 → 记事本。

6. 按 `Ctrl+F` 搜索 `subscribedby`。你会看到它后面跟着一串数字，那是账号 ID。
   - 同一串数字出现次数最多的，通常就是**你自己**（你订阅得最多）。
   - 拿不准的话，**别继续**，退回方案一或直接用方案三。

7. 找到 `subscribedby "别人的账号"` 的那些条目：从它上方那行 `"一长串数字"` 开始，
   到对应的一组 `}` 结束，**整块删掉**。

   一个条目长这样，删的是从 `"1234567890"` 到它自己的 `}` 的整段：
   ```
   "1234567890"
   {
       "manifest"      "..."
       "timetouched"   "..."
       "subscribedby"  "别人的账号"
   }
   ```

8. 保存（记事本默认 UTF-8 就行），关闭。

9. 启动 Steam。

### 出问题怎么办

删错一个括号，Steam 可能把你的订阅列表清空、或者重新下载。
**用第 4 步的备份覆盖回去就行**，然后再来一次。

## 方案三：彻底重建（最狠，会重下自己的壁纸）

适合「方案二不敢动手」或者「怎么都清不干净」的情况。社区里验证过很多次。

1. 完全退出 Steam 和小红车（同方案二第 1、2 步）。
2. 打开 `<你的Steam库>\steamapps\workshop`。
3. 删掉 `appworkshop_431960.acf`；
   再删掉 `content\431960` 整个文件夹（这是所有已下载的壁纸）。
4. 启动 Steam，**只登录你自己的账号**。
5. 随便订阅一张壁纸（触发 Steam 重建记录）。
6. Steam 会生成新的 `appworkshop_431960.acf`，并且只下载你自己账号订阅的壁纸。

**代价**：你自己的壁纸会全部重新下载。壁纸多的话是几十 GB。

**之后千万不要再登那个号**，一登就前功尽弃。

---

## 三条禁忌（比做什么更重要）

- ❌ **别再登那个号**。包括在 Steam 里切过去。这是唯一会让别人订阅整批复活的动作。
- ❌ **别手动删 `content\431960` 里「还有订阅记录」的文件夹**。
  官方文档明确写了：手动删掉，Steam 会发现文件缺失，自动重新下载补回来，
  白删一次还多花流量。
- ❌ **别在 Steam 运行时改那个记录文件**。写不进去，Steam 退出时还会把它覆盖回原样。

## 关于官方那个修复工具

小红车目录下有个 `bin\steamredownloadfixer32.exe`，官方帮助页推荐用它修
「Steam 反复重新下载」的问题。

早期版本有个路径问题：它会在 `steamapps\common\workshop` 下面找记录文件，
而现在的版本实际放在 `steamapps\workshop`，对不上。**这个路径问题已经修复了**，
可以正常使用。

用法（官方页面步骤）：

1. 完全退出 Steam。
2. 打开小红车安装目录（默认 `C:\Program Files (x86)\Steam\steamapps\common\wallpaper_engine`）。
3. 运行里面的 `bin\steamredownloadfixer32.exe`。
4. 重启 Steam，然后对小红车做一次「验证文件完整性」
   （库 → 右键 Wallpaper Engine → 属性 → 已安装文件 → 验证游戏文件完整性）。
5. 如果还不行，再走方案二或方案三。

注意：Steam 下载缓存每坏一次就得重跑一次，这是 Steam 自己的问题，小红车修不了。

## 懒得动手

- 只试**方案一**：两分钟，能解决「隐藏订阅」那一类。
- 或者用配套的小工具：它只删记录里别人账号的条目，不动你自己的壁纸，
  改前自动备份、随时能还原，也不用登录 Steam。
