# 小红车壁纸反复下载、硬盘被占满：手动解决教程

> 不用装任何第三方工具，只用 Steam 和小红车自带的功能。
> 按「代价从小到大」排列，**先看自己在哪一步，再对号入座**，别跳步。

---

## 先判断你在哪一步

| 现象 | 用哪个方案 |
|---|---|
| Steam 正在下载别人的壁纸，下载进度条还在动 | **方案一**（最轻，先做这个） |
| 别人的壁纸已经下完，文件夹躺在硬盘上了 | **方案二**（改订阅记录） |
| 删了文件，但每次开 Steam 又自动下回来 | **方案三**（清那个号在本机的登录数据） |
| 已经不想折腾了 | **兜底：卸载重装** |

**为什么会这样**：Steam 的创意工坊订阅是**跟着账号走**的，不是跟着电脑走。
这台电脑登录过别人的 Steam 账号，Steam 就会把那个号订阅的壁纸也下载下来。

**先说清一个常见误解**：关掉 Steam 的「云同步」**没有用**。
云同步只管游戏存档文件，创意工坊订阅是账号级的数据，两套东西。
关掉只会让你自己的游戏存档失去云端备份。

---

## 方案一：下载还没完成（最轻，先做这个）

**关键在时机：在它下完之前打断。**
已经下完的文件删了会触发 Steam 重新下载；而**下载中的临时文件删掉是安全的**。

1. **先暂停**：打开 Steam 的「下载」页，把壁纸的下载暂停，别让它继续跑。
2. **完全退出 Steam**：托盘图标右键 → 退出。
   然后按 `Ctrl+Shift+Esc` 打开任务管理器，确认没有 `steam.exe` 和 `steamwebhelper.exe`。
   **这一步不要省，Steam 开着的时候删，它会把文件写回来。**
3. 打开下载缓存目录：
   ```
   <你的Steam库>\steamapps\workshop\downloads
   ```
   里面的 `431960` 文件夹就是小红车（431960 是它的编号），
   同目录下文件名带 `431960` 的也是相关文件。
4. **把 `431960` 文件夹删掉**，`downloads` 下带 `431960` 的文件也一起删。
   这些都是"正在下载"的临时文件，删了不影响你已经装好的壁纸。
5. 运行小红车自带的修复程序：
   ```
   <你的Steam库>\steamapps\common\wallpaper_engine\bin\steamredownloadfixer32.exe
   ```
   **不跑这一步，下次打开 Steam 它还会接着下。**
6. 启动 Steam 看还下不下。还在下，就从第 1 步重来一遍。

### 这一步只删什么、不删什么

- ✅ 只删 `workshop\downloads` 里的东西（下载中的缓存）。
- ❌ **别删 `workshop\content\431960`**：那是已经装好的壁纸，删了 Steam 会重新下载。
- ❌ **别删 `workshop\state_431960_*.patch`**：下载状态记录，删了会触发重新校验、重新下载。

## 方案二：壁纸已经下完了

文件已经进了 `content\431960`，这时直接删文件没用——Steam 会发现文件缺失，重新下回来。
要断根得改「订阅记录」，不是删文件。

原理：Steam 在本机留了一个记录文件，里面写着"哪条壁纸是哪个账号订阅的"。
把属于别人账号的条目删掉，Steam 就不再认它们，还会连已下载的文件一起清掉；
而且不会写回来——**除非你再登那个号**。

改之前必须备份，这是唯一不能省的一步。

### 步骤

1. **完全退出 Steam**
   托盘图标右键 → 退出。任务管理器确认没有 `steam.exe` / `steamwebhelper.exe`。

2. **完全退出小红车**
   包括右下角托盘里的 `ui32.exe`。只关掉壁纸画面不算退出。

3. 打开：
   ```
   <你的Steam库>\steamapps\workshop
   ```
   里面有一个 `appworkshop_431960.acf`。

4. **先备份**：把它复制一份，改名成 `appworkshop_431960.acf.备份`，放同一个文件夹。

5. 右键 `appworkshop_431960.acf` → 打开方式 → 记事本。

6. 按 `Ctrl+F` 搜 `subscribedby`，它后面那串数字是账号 ID。
   - 同一串数字出现次数最多的，通常就是**你自己**（你订阅得最多）。
   - 拿不准就别继续，**用方案一或方案三**。

7. 把 `subscribedby "别人的账号"` 的条目整块删掉：从它上面那行 `"一长串数字"` 开始，
   到对应的一组 `}` 结束。

   ```
   "1234567890"
   {
       "manifest"      "..."
       "timetouched"   "..."
       "subscribedby"  "别人的账号"
   }
   ```

8. 保存（记事本默认 UTF-8），关闭，启动 Steam。

### 改坏了怎么办

用第 4 步的备份覆盖回去就行，然后再来一次。

## 方案三：删了还反复下回来

说明 Steam 里还留着那个账号在这台电脑上的登录数据，所以每次都认为"该下"。
要把那个号在本机的痕迹清掉。

1. 完全退出 Steam（同上）。
2. 打开 Steam 的**安装目录**（不是游戏库）：
   ```
   <Steam安装目录>\userdata
   ```
   里面是一串 9 位数字的文件夹，每个对应一个在这台电脑登过的账号。
3. 找到那个**别人的号**对应的文件夹，整个删掉。
   怎么判断是哪个？看文件夹的修改时间，或者逐个进去看 `config\localconfig.vdf` 里的昵称。
4. 启动 Steam。

**风险**：删掉的那个号会丢失它在这台电脑上的本地设置、成就缓存等（云端订阅不受影响）。
所以只在你确定不再用那个号时做；**不确定就别删，改用方案二**。

## 兜底：卸载重装小红车

如果你已经打算"全删了重来"，**别手动删 acf 和 content，直接卸载重装更省事、更不容易出错**：

Steam 库 → 右键 Wallpaper Engine → 管理 → 卸载 → 再重新安装。
重装后只登自己的号，重新订阅你要的壁纸。

代价和手动删一样（自己的壁纸全部重下），但少一步"删错文件把 Steam 搞抽风"的风险。

---

## 三条禁忌（比做什么更重要）

- ❌ **别再登那个号**。包括在 Steam 里切过去。这是唯一会让别人订阅整批复活的动作。
- ❌ **别手动删 `content\431960` 里「还有订阅记录」的文件夹**。
  官方文档明确写了：手动删掉，Steam 会发现文件缺失，自动重新下载补回来，白删还多花流量。
- ❌ **别在 Steam 运行时改那个记录文件**。写不进去，Steam 退出时还会覆盖回原样。

---

## 关于官方那个修复程序

`bin\steamredownloadfixer32.exe`，小红车官方帮助页推荐用它修「Steam 反复重新下载」。
早期版本有个路径问题（去 `steamapps\common\workshop` 找记录文件，实际在 `steamapps\workshop`），
**这个问题已经修复了**，现在可以正常用。

用法：

1. 完全退出 Steam。
2. 打开小红车安装目录（默认 `C:\Program Files (x86)\Steam\steamapps\common\wallpaper_engine`）。
3. 运行里面的 `bin\steamredownloadfixer32.exe`。
4. 重启 Steam，然后对小红车做一次「验证文件完整性」
   （库 → 右键 Wallpaper Engine → 属性 → 已安装文件 → 验证游戏文件完整性）。
5. 还不行，再走方案二或方案三。

注意：Steam 下载缓存每坏一次就得重跑一次，这是 Steam 自己的问题，小红车修不了。

---

## 补充：官方「全部取消订阅」什么时候用

官方文档里有个 **Unsubscribe From All**（工坊页面 → Your files → Subscribed Items），
它会把你**自己账号**的所有订阅一次清空，包括那些在小红车里看不见的隐藏订阅。

**不适合本文这个场景**——为了清别人的号，先把自己的订阅全清空，代价太大，正常用户不会这么干。
只适合：你自己的订阅列表乱了、里面有一堆看不见的僵尸订阅。用之前想清楚。

## 懒得动手

用配套的小工具：只删记录里别人账号的条目，不动你自己的壁纸，
改前自动备份、随时能还原，也不用登录 Steam。
