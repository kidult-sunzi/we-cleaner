# 小红车壁纸反复下载、硬盘被占满：手动解决教程

> 不用装任何第三方工具，只用 Steam 和小红车自带的功能。
>
> **一句话结论：能改记录文件就改记录文件。**
> 改记录是一次到位、连已下完的文件一起清、你自己的壁纸一张不用重下；
> 实在不会改，再往下用「下载中打断」，但那只止血，可能反复。

---

## 为什么「删文件」不如「改记录」

Steam 要不要下载一个工坊物品，看的是记录文件里写的「这条是谁订阅的、还要不要」：

| 你做的事 | Steam 看到什么 | 结果 |
|---|---|---|
| 删下载缓存 / 删 `content` 里的文件夹 | 记录还在 → 「还要」 | **下回来** |
| 删记录里别人账号的条目 | 需求没了 → 「不要了」 | 连已装记录和磁盘文件**一起清**，而且不会写回来 |

所以顺序应该是：**先改记录，改不了再退而求其次**。

---

## 先判断你在哪一步

| 现象 | 用哪个 |
|---|---|
| 硬盘里有别人的壁纸（正在下，或已经下完） | **方案一：改记录**（首选） |
| 不会改文件、或不想动记录 | **方案二：下载中打断**（退路，可能反复） |
| 改过记录也删过缓存，还是每次开 Steam 都下 | **方案三：清那个号在本机的登录数据** |
| 不想折腾了 | **兜底：卸载重装** |
| 还没被下，只是经常要借号给别人 | **预防：登录前挪走安装清单** |

**为什么会这样**：Steam 的创意工坊订阅**跟着账号走**，不跟电脑走。
这台电脑登录过别人的 Steam 账号，Steam 就会把那个号订阅的壁纸也下载下来。

**常见误解**：关掉 Steam 的「云同步」**没有用**。云同步只管游戏存档，创意工坊订阅是账号级数据，两套东西。

---

## 方案一（首选）：改订阅记录

原理：把记录里属于别人账号的条目删掉，Steam 就不再认它们，
**连已经下完的文件也会自己清掉**——所以这一步不需要你去删 `content` 里的东西。

改之前必须备份，这是唯一不能省的一步。

### 步骤

1. **完全退出 Steam**
   托盘图标右键 → 退出。按 `Ctrl+Shift+Esc` 打开任务管理器，
   确认没有 `steam.exe` 和 `steamwebhelper.exe`。

2. **完全退出小红车**
   包括右下角托盘里的 `ui32.exe`。只关掉壁纸画面不算退出。

3. 打开：
   ```
   <你的Steam库>\steamapps\workshop
   ```
   里面有一个 `appworkshop_431960.acf`。

4. **先备份**：复制一份，改名成 `appworkshop_431960.acf.备份`，放同一个文件夹。

5. 右键 `appworkshop_431960.acf` → 打开方式 → 记事本。

6. 按 `Ctrl+F` 搜 `subscribedby`，它后面那串数字是账号 ID。
   - 同一串数字出现次数最多的，通常就是**你自己**（你订阅得最多）。
   - 拿不准就别继续，改用方案二。

7. 把 `subscribedby "别人的账号"` 的条目整块删掉：
   从它上面那行 `"一长串数字"` 开始，到对应的一组 `}` 结束。

   ```
   "1234567890"
   {
       "manifest"      "..."
       "timetouched"   "..."
       "subscribedby"  "别人的账号"
   }
   ```

8. 保存（记事本默认 UTF-8），关闭。

9. **启动 Steam**。它会自己把别人那些已下完的壁纸清掉，你不用手动删 `content`。

### 为什么说这一步最省

- 不用删下载缓存，不用管 `content`；
- 你自己的壁纸一张都不用重下；
- 一次做完，不会反复——除非你再登那个号。

### 改坏了怎么办

用第 4 步的备份覆盖回去，再来一次。

---

## 方案二（退路）：不会改文件，就在下载完成前打断

**先说清局限**：这一步只删「正在下载的临时文件」，**记录还在**，
所以 Steam 下次启动可能又下回来。它能救急（尤其硬盘快满了的时候），但不保证一次干净。

**关键在时机：在它下完之前打断。** 已经下完的删了会触发重新下载；下载中的临时文件删掉是安全的。

1. **先暂停**：打开 Steam 的「下载」页，把壁纸下载暂停，别让它继续跑。
2. **完全退出 Steam**：托盘图标右键 → 退出。任务管理器确认没有 `steam.exe` / `steamwebhelper.exe`。
   **这一步不要省，Steam 开着删，它会把文件写回来。**
3. 打开下载缓存目录：
   ```
   <你的Steam库>\steamapps\workshop\downloads
   ```
   里面的 `431960` 文件夹就是小红车（431960 是它的编号），同目录下文件名带 `431960` 的也是相关文件。
4. **把 `431960` 文件夹删掉**，`downloads` 下带 `431960` 的文件也一起删。
   这些都是下载中的临时文件，删了不影响已装好的壁纸。
5. 运行小红车自带的修复程序：
   ```
   <你的Steam库>\steamapps\common\wallpaper_engine\bin\steamredownloadfixer32.exe
   ```
   **不跑这一步，下次打开 Steam 它还会接着下。**
6. 启动 Steam 看还下不下。还在下，就从第 1 步重来一遍。

### 这一步只删什么、不删什么

- ✅ 只删 `workshop\downloads` 里的（下载中的缓存）。
- ❌ **别删 `workshop\content\431960`**：已装好的壁纸，删了 Steam 会重新下载。
- ❌ **别删 `workshop\state_431960_*.patch`**：下载状态记录，删了会触发重新校验、重新下载。

### 反复几次也压不住怎么办

说明记录还在——回到**方案一**改记录，或者看方案三。

---

## 方案三：删了还反复下回来

说明 Steam 里还留着那个账号在这台电脑上的登录数据，所以每次都认为「该下」。

1. 完全退出 Steam。
2. 打开 Steam 的**安装目录**（不是游戏库）：
   ```
   <Steam安装目录>\userdata
   ```
   里面是一串 9 位数字的文件夹，每个对应一个在这台电脑登过的账号。
3. 找到那个**别人的号**，整个文件夹删掉。
   判断是哪个：看文件夹的修改时间，或者进去看 `config\localconfig.vdf` 里的昵称。
4. 启动 Steam。

**风险**：被删的那个号会丢掉它在这台电脑上的本地设置、成就缓存（云端订阅不受影响）。
只在你确定不再用那个号时做；不确定就别删，回到方案一。

---

## 兜底：卸载重装小红车

如果你已经打算「全删了重来」，**别手动删 acf 和 content，直接卸载重装更省事、更不容易出错**：

Steam 库 → 右键 Wallpaper Engine → 管理 → 卸载 → 再重新安装。
重装后只登自己的号，重新订阅你要的壁纸。

代价和手动删一样（自己的壁纸全部重下），但少一步「删错文件把 Steam 搞抽风」的风险。

---

## 预防：经常借号，就在登录前先挡一下

如果这台电脑经常要登别人的号（代练、借号、家庭共享），别等它下完再清——**事前**挡掉。

原理：`steamapps\appmanifest_431960.acf` 是小红车的**安装清单**，Steam 靠它判断
「这个软件装了没有、要不要更新」。把它挪走，Steam 就认为这台电脑没装小红车，
**就不会为它下载任何创意工坊内容**。

1. 完全退出 Steam。
2. 打开 `<你的Steam库>\steamapps`，找到 `appmanifest_431960.acf`。
3. 把它**剪切**（不是删除）到桌面或别的文件夹，临时放着。
4. 再启动 Steam，登录别人的号。

用完、换回自己的号之后，把文件挪回原路径，重启 Steam 即可。

**要注意**：

- 它只防「新下载」，**不会清掉已经下下来的**——硬盘里已有的，仍然按方案一/二处理。
- 期间小红车在 Steam 库里显示「未安装」，不能从 Steam 启动或更新；
  想用就换回自己的号，或者直接运行 `steamapps\common\wallpaper_engine` 里的程序。
- 如果那个号本身没买小红车，移走清单后可能启动不了，那就别用这招。
- 恢复后 Steam 可能提示校验或更新，让它正常走完就行。

---

## 三条禁忌（比做什么更重要）

- ❌ **别再登那个号**。包括在 Steam 里切过去。这是唯一会让别人订阅整批复活的动作。
- ❌ **别手动删 `content\431960` 里「还有订阅记录」的文件夹**。
  官方文档明确写了：手动删掉，Steam 会发现文件缺失，自动重新下载补回来，白删还多花流量。
- ❌ **别在 Steam 运行时改那个记录文件**。写不进去，Steam 退出时还会覆盖回原样。

---

## 关于官方那个修复程序

`bin\steamredownloadfixer32.exe`，小红车官方帮助页推荐用它修「Steam 反复重新下载」。
早期版本有个路径问题（去 `steamapps\common\workshop` 找记录文件，实际在 `steamapps\workshop`），
**这个问题已经修复了**，现在可以正常用。

用法：

1. 完全退出 Steam。
2. 打开小红车安装目录（默认 `C:\Program Files (x86)\Steam\steamapps\common\wallpaper_engine`）。
3. 运行里面的 `bin\steamredownloadfixer32.exe`。
4. 重启 Steam，然后对小红车做一次「验证文件完整性」
   （库 → 右键 Wallpaper Engine → 属性 → 已安装文件 → 验证游戏文件完整性）。
5. 还不行，再走方案一或方案三。

注意：Steam 下载缓存每坏一次就得重跑一次，这是 Steam 自己的问题，小红车修不了。

---

## 补充：官方「全部取消订阅」什么时候用

官方文档里有个 **Unsubscribe From All**（工坊页面 → Your files → Subscribed Items），
会把你**自己账号**的所有订阅一次清空，包括小红车里看不见的隐藏订阅。

**不适合本文场景**——为了清别人的号，先把自己的订阅全清空，代价太大。
只适合：你自己的订阅列表乱了、里面有一堆看不见的僵尸订阅。用之前想清楚。
