怎么用

  1. 双击打开。Steam 正在运行的话，点一下「一键退出 Steam」——工具也会自动帮你退。
  2. 在上面点一下你自己的账号（显示昵称、壁纸数量、账号尾号，不用记数字）。
  3. 点蓝色按钮「一键清理」，确认一次。完成后可以点「一键启动 Steam」开回去。

它会做什么、不会做什么

会做删掉 acf 里其他账号的订阅记录；清 431960 的下载缓存（送回收站）
不会做不删壁纸文件、不改云端订阅、不改 Steam 程序、不读取账号密码
网络完全不联网，没有上传，没有统计
安全网每次修改前自动备份，界面上有「还原备份acf文件」随时回退
第一次打开可能被拦。 exe 没有代码签名，Windows 可能弹「已保护你的电脑」，杀软也可能误报。 点「更多信息 → 仍要运行」即可。执行清理时 360 等会弹「是否允许删除文件」，选允许。 想核对文件是否被改动，比对上面的 SHA256。
详细说明
它到底改了什么？（给懂的人看）

只改 SteamLibrary\steamapps\workshop\appworkshop_431960.acf 里的 WorkshopItemDetails 条目：按 subscribedby 字段判断归属， 删掉非主账号的条目，保留你自己的。Steam 生成的 acf 顶层本身多一个 }， 所以校验用的是「删除前后括号差值守恒」，不是绝对配平。写入前会检查 Steam 进程、删除条数、 结构是否合法，任一异常立即中止、文件不动。

清缓存走 Windows 系统接口送回收站（非永久删除），且只在本地固定磁盘上工作—— 移动硬盘和网络盘会被拦下，避免变成不可恢复的删除。
