# 关于杀毒软件提示和 Windows 拦截

## 一句话

这是个人开发的开源小工具，**没有购买代码签名证书**。部分杀软或 Windows 首次运行时会提示风险，那是针对「未签名的新程序」的常规提醒，不是查到了病毒。

## 你可以自己核对三件事

1. **源码公开**：GitHub 上能看到它做的每一件事——不联网、不读密码、不改 Steam 程序。
2. **行为可验证**：工具只改一个配置文件；下载缓存由你自己在资源管理器里删除，改配置前自动备份，全流程有诊断日志。
3. **文件可校验**：下载页贴了 SHA256，算一遍就知道文件有没有被改过。

校验方法（Windows 自带）：

```powershell
Get-FileHash -Algorithm SHA256 .\we-cleaner.exe
```

和下载页上的哈希对不上，就说明文件被替换过，**不要运行**。

## 两种提示要分清

**第一种：Windows「已保护你的电脑」蓝窗**
未签名的 exe 首次运行都会这样。点「更多信息」→「仍要运行」。
如果连这个按钮都没有，说明系统的 SmartScreen 策略更严，可以在文件属性里勾「解除锁定」再试。

**第二种：360 / 电脑管家 / 火绒弹窗**
在执行「一键清理」时出现，因为它看到「一个陌生的未签名程序在改 Steam 的配置文件」。这叫**主动防御 / 行为拦截**，不是静态查毒。清缓存那一步工具只打开文件夹、不删文件，不会触发这一类拦截。

- 弹窗里选「允许本次操作」
- 或者把 `we-cleaner.exe` 加进安全软件的信任列表 / 白名单
- 加过之后就不会再拦

本工具的行为已经尽量收敛：正常退出 Steam（不杀进程）、不替用户删除下载缓存（只打开文件夹）、不写自启动、不联网、不读账号密码。

## 万一你真不放心

完全可以不下载。这个工具解决的问题（多账号壁纸混在一起）视频里已经讲完了，动手能力强的可以自己改 acf，或者直接用源码运行：

```bash
pip install -r requirements.txt
python app.py
```
